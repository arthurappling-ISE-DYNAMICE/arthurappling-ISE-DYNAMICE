# 09_SOPs

## What Belongs Here
- Standard Operating Procedures: repeatable, step-by-step processes with a
  clear pass criteria and error map.

## What Does Not Belong Here
- One-time decisions (→ `03_Engineering_Decisions/`).
- Checklists meant to be run through quickly rather than followed as a
  procedure (→ `10_Checklists/`).

## Example Entries
- `SOP_TEMPLATE.md`

## How Future AI Sessions Should Update It
Use the template for every new SOP. Every SOP must have a named owner and a
"last updated" date so staleness is visible at a glance.
