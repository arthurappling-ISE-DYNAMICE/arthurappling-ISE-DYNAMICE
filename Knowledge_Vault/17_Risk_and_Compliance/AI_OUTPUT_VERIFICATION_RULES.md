# AI Output Verification Rules

- **Never trust AI legal/financial/security claims without verification.**
  A confident-sounding answer is not the same as a verified one.
- **Primary sources matter.** Verify against the actual law, contract,
  documentation, or system state — not against what an AI model recalls.
- **Use AI for drafting and analysis, not blind authority.** AI output is a
  starting draft to verify, not a final answer to ship.
- **For client-facing legal/compliance content, require source
  verification** before it goes to a client — no exceptions.
- **Flag uncertainty clearly.** If a claim can't be verified, say so
  explicitly rather than presenting it as fact.
- **Never fabricate citations, laws, cases, prices, or technical
  guarantees.** If a citation or number can't be confirmed, do not
  state it as if it were confirmed.
