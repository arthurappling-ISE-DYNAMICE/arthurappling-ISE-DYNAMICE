# 11_Release_History

## What Belongs Here
- A running index of shipped versions and what each one delivered.

## What Does Not Belong Here
- Full audit reports (those live in `tools/command_deck/docs/v3.0/`) — this
  folder holds the index/summary, not the raw report.

## Example Entries
- `RELEASE_INDEX.md`

## How Future AI Sessions Should Update It
Append a new line per shipped version. Never rewrite history — only add.
Cross-reference the audit report location for detail.
