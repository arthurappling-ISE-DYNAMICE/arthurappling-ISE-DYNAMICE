# 03_Engineering_Decisions

## What Belongs Here
- Dated, specific engineering decisions with context, options considered,
  chosen approach, reason, risks, rollback, and status.
- One file per decision, named `YYYY-MM-DD_short_description.md`.

## What Does Not Belong Here
- General architecture principles that don't map to a single decision
  (→ `02_Architecture/`).
- Lessons learned after the fact from an incident (→ `04_Lessons_Learned/`).

## Example Entries
- `DECISION_LOG_TEMPLATE.md`
- `2026-07-05_v4_6_hosting_strategy.md`

## How Future AI Sessions Should Update It
Use `DECISION_LOG_TEMPLATE.md` for every new entry. Log the decision when it
is made, not retroactively reconstructed from memory — capture the real
options considered at the time.
