# 06_Future_Features_Shelf

## What Belongs Here
- Parked feature ideas that are not part of the current mission.
- Each entry: Status (PARKED), why it matters, when to revisit, risk if
  added too early.

## What Does Not Belong Here
- Anything currently being built (that's just... the current mission).
- Vague brainstorm noise with no clear "when to revisit" condition.

## Example Entries
- `FUTURE_FEATURES_BACKLOG.md`

## How Future AI Sessions Should Update It
Add new ideas here instead of pursuing them mid-mission (see root
`CLAUDE.md` → Current Mission Discipline). When a parked idea's "when to
revisit" condition is met, move it into an active decision/mission — don't
silently pick it back up.
