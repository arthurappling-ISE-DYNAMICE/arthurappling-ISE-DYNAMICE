# 20_Operating_Rhythm

## Purpose
Define the recurring cadence Arthur uses to run Prime Pathwy — daily,
weekly, and monthly check-ins — plus a simple filter for evaluating new
ideas so the operating rhythm stays disciplined.

## What Belongs Here
- The daily/weekly/monthly rhythm checklist.
- The decision filter used to evaluate any new idea or tool.

## What Does Not Belong Here
- Specific mission plans or session logs (→ `13_AI_Session_Logs/`).
- One-time engineering decisions (→ `03_Engineering_Decisions/`).

## How Future AI Sessions Should Update It
- Update the rhythm only when Arthur changes his actual cadence — this
  should describe real practice, not an aspirational routine.
- Apply `DECISION_FILTER.md` before recommending any new tool, feature, or
  mission be added to the active roadmap.

## Warning
**Never store secrets.** No credentials, keys, or private data belong in
this folder.
