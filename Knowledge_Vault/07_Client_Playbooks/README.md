# 07_Client_Playbooks

## What Belongs Here
- Per-industry or per-client playbooks: pain points, current workflow,
  proposed SYS_OS solution, integrations, dashboard modules, automation
  opportunities, security concerns, training plan, pricing notes, success
  metrics.

## What Does Not Belong Here
- Actual client PII, contracts, or confidential data — playbooks describe
  the approach and pattern, not private client records.
- Generic marketing copy (→ `08_Marketing/`).

## Example Entries
- `CLIENT_PLAYBOOK_TEMPLATE.md`

## How Future AI Sessions Should Update It
Copy the template for each new client engagement or vertical. Redact
anything that would identify a specific client if the file could ever be
shared externally.
