# Demo and Content Ideas

- **Instagram demo concepts:** short clips showing a real dashboard action
  (login → data persists → RLS isolation proof) rather than staged visuals.
- **YouTube tutorial ideas:** walkthroughs of real, shipped features once
  hosting is live — not aspirational features.
- **QR code funnel idea:** QR code on printed/physical materials leading to
  a landing page → questionnaire → consultation booking.
- **Website → questionnaire → consultation flow:** structured intake before
  a live conversation, so the consult starts from real client context.
- **Free webinar concept:** educational session demonstrating a real,
  working capability as a trust-building, non-salesy touchpoint.
- **Value-first messaging:** lead with the client problem solved, not the
  technology used to solve it.
- **Do not market claims the system cannot prove.** Every public claim must
  be checkable against verified state (see root `CLAUDE.md` Client Trust
  Standard).
