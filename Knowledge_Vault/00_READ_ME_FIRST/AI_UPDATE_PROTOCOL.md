# AI Update Protocol

When Arthur brings a new AI tool, Instagram post, competitor, or research
asset into a session, run this intake checklist before filing anything.

## Ask, In Order

1. Does it strengthen Prime Pathwy?
2. Does it solve a real client problem?
3. Does it reduce risk or cost?
4. Does it fit the current roadmap?
5. Should it be implemented now, parked, or discarded?

## Then File It Into One Of

- **`05_Competitor_Intelligence/`** — a competitor's product, tactic, or
  business model. Extract the pattern, note the caution, note the Prime
  Pathwy adaptation.
- **`06_Future_Features_Shelf/`** — a feature idea that has value but is not
  part of the current mission.
- **`12_Research_Archive/`** — raw research material, articles, prompts,
  or assets that may contain useful patterns but are not yet classified.
- **`03_Engineering_Decisions/`** — if the intake *resulted* in an actual
  architecture or engineering decision being made.
- **Discard** — if it fails all five questions, do not create a file.

## Guardrails

- Never let an external tool or trend interrupt the current mission
  (see root `CLAUDE.md` → Mission Separation Rules and Current Mission
  Discipline).
- Never implement anything from this intake without explicit authorization
  from Arthur — this protocol is for classification, not action.
