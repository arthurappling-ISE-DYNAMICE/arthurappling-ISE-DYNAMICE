# Command Library Concept

The 50-command manual eventually becomes a SYS_OS command library.

## Future States

- Prompt library
- Command center
- Business engines
- Client-facing buttons
- Workflow automation
- AI chooses the correct workflow based on form input

## Rule

Customers should not see raw prompts. Customers should interact with
simple forms, buttons, and outcomes — the prompt/command complexity stays
inside the platform, never exposed as something the client has to write or
understand themselves.
