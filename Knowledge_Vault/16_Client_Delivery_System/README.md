# 16_Client_Delivery_System

## Purpose
Define how Prime Pathwy actually delivers work to clients — the phased
framework, onboarding intake, and trust standards that keep delivery
consistent across engagements.

## What Belongs Here
- The client delivery framework and its phases.
- Onboarding questionnaire templates.
- Delivery-stage standards (trust standard, quality bar, pricing tiers as
  they relate to delivery phase).

## What Does Not Belong Here
- Actual client PII, contracts, or confidential business data — templates
  and frameworks only.
- Pricing strategy detail beyond what's needed for delivery context (→
  `18_Monetization_and_Pricing/`).
- Marketing copy and demo ideas (→ `08_Marketing/`).

## How Future AI Sessions Should Update It
- Update the framework only when a real engagement reveals a gap or a
  phase needs adjusting — not speculatively.
- Copy `CLIENT_ONBOARDING_QUESTIONNAIRE_TEMPLATE.md` per engagement rather
  than editing the template itself.

## Warning
**Never store secrets.** No client credentials, API keys, or private data
in any file here.
