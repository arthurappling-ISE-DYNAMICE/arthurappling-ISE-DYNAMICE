# 04_Lessons_Learned

## What Belongs Here
- Lessons extracted from real incidents, recoveries, debugging sessions, or
  workflows that succeeded or failed.
- Patterns that should change future behavior (e.g., checkpoint discipline,
  credential setup gotchas).

## What Does Not Belong Here
- Raw incident logs or transcripts — extract the lesson, don't paste the
  whole session.
- Decisions that haven't been tested yet (→ `03_Engineering_Decisions/`).

## Example Entries
- `CHECKPOINT_RECOVERY_LESSON.md`
- `SUPABASE_RLS_LESSON.md`

## How Future AI Sessions Should Update It
Add a new lesson file whenever a mission produces a reusable lesson —
successful or failed. Keep each lesson short: what happened, what fixed it,
what to do differently next time.
