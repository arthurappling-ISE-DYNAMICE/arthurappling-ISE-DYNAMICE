# Prompt Library Index

A permanent index of reusable Prime Pathwy prompts, organized by category.
Each entry should be built from `PROMPT_TEMPLATE.md` and stored as its own
file once tested.

## Categories

- **Architecture audit prompts** — reviewing SYS_OS or client system
  architecture against Prime Pathwy principles.
- **Deployment prompts** — guiding a deployment session end to end.
- **Security review prompts** — auditing for exposed secrets, weakened
  RLS, or unsafe config.
- **Supabase/RLS prompts** — verifying auth, persistence, and isolation.
- **Hosting prompts** — building/validating a curated public deploy
  artifact.
- **Client onboarding prompts** — running an AI-guided client interview.
- **Competitor analysis prompts** — producing a structured competitor
  intelligence entry.
- **Knowledge Vault update prompts** — classifying and filing new
  information into the vault correctly.
- **Recovery/checkpoint prompts** — restarting cleanly from a known-good
  state after a loop or failure.
- **Release report prompts** — producing a release/audit report for a
  shipped version.
- **Marketing/content prompts** — generating value-first demo and content
  ideas.

## Rule

**Prompts must be tested, refined, and versioned before being trusted.** A
prompt only earns a place in this library after it has actually produced a
reliable result — untested prompts stay in the working session.
